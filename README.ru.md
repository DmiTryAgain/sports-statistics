# Sports Statistics Bot

Telegram-бот для учёта спортивных упражнений. Поддерживает русский и английский языки.

Бот позволяет:
- Добавлять выполненные упражнения текстом или через кнопки
- Просматривать статистику за любой период
- Быстро повторять частые упражнения одним нажатием (Quick-Add)

## Требования

- Go 1.24+
- PostgreSQL
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## Установка и запуск

### 1. Клонирование

```bash
git clone https://github.com/DmiTryAgain/sports-statistics.git
cd sports-statistics
```

### 2. Настройка конфигурации

```bash
cp config/local.toml.dist config/local.toml
```

Откройте `config/local.toml` и заполните:

```toml
[Bot]
Token = "ваш-токен-от-BotFather"
Name = "имя_вашего_бота"
ReplyFormat = "markdown"
Debug = false
Timeout = "30s"

[Database]
Addr     = "localhost:5432"
User     = "postgres"
Database = "sport_statsrv"
Password = "postgres"
```

### 3. Создание базы данных

```bash
createdb sport_statsrv
psql -d sport_statsrv -f docs/schema.sql
```

### 4. Сборка и запуск

```bash
make build
make run
```

Бот начнёт слушать обновления от Telegram. Логи пишутся в `app.log`.

## Использование

### Начало работы

Отправьте боту `/start` — появится клавиатура с тремя кнопками: **Добавить**, **Показать**, **Помощь**.

Все команды можно вводить как текстом, так и через кнопки.

### Добавление упражнений

Текстовый формат: `<команда> <упражнение> [параметры]`

Команды: `сделал`, `добавь`, `add`

**Примеры:**

```
сделал подтягивания 15
добавь жим лёжа 80кг 10
сделал бег 5км 25мин
сделал планка 90сек
сделал удержание веса 40кг 30сек
добавь приседания 60кг 12
сделал ходьба 3км
сделал бег 30мин
```

Параметры можно писать слитно (`80кг`) или раздельно (`80 кг`). Поддерживаются единицы:
- Вес: `кг`, `г` (`kg`, `g`, `lbs`)
- Дистанция: `км`, `м` (`km`, `m`)
- Время: `ч`, `мин`, `сек` (`h`, `min`, `sec`)

Составные значения времени суммируются: `1ч 30мин` = 90 минут.

### Просмотр статистики

Текстовый формат: `<команда> <упражнения> [период]`

Команды: `покажи`, `показать`, `show`

**Примеры:**

```
покажи подтягивания за неделю
покажи всё за сегодня
покажи жим лёжа приседания за месяц
покажи подтягивания за год
покажи всё
```

Периоды: `сегодня`, `вчера`, `неделя`, `прошлую неделю`, `позапрошлую неделю`, `месяц`, `прошлый месяц`, `позапрошлый месяц`, `год`, `прошлый год`, `позапрошлый год`. Без указания периода — за всё время.

Также поддерживаются дни недели: `пн`, `вт`, `ср`, `чт`, `пт`, `сб`, `вс` (и полные формы: `понедельник`, `вторник`, ...). Если день уже прошёл на этой неделе — показывает этот день текущей недели; если ещё не наступил — прошлой; если сегодня — с 00:00 до текущего момента.

Также поддерживаются даты: `15.03.2026` или диапазон `01.03.2026-15.03.2026`.

Пример вывода:

```
упражнение      вес     кол-во    подходы
подтягивания    -       22        2
жим лёжа        60кг    10        1
жим лёжа        80кг    18        2
```

### Справка

```
помощь
помощь добавь
помощь покажи
```

### Кнопочный режим

Нажмите **Добавить** — бот предложит выбрать упражнение из списка, затем пошагово запросит параметры (вес, количество, дистанцию, время) в зависимости от типа упражнения.

Если вы часто делаете одни и те же упражнения, бот покажет кнопки **Quick-Add** — добавление одним нажатием на основе вашей истории.

После добавления через кнопки бот покажет подсказку с готовой текстовой командой для быстрого копирования и повторного использования.

## Поддерживаемые упражнения

**Обычные:** подтягивания, отжимания, брусья, пресс, приседания, выпады, бёрпи, скакалка, гиперэкстензия, подъём ног, выход силы

**С весом:** жим лёжа, становая тяга, тяга верхнего блока, жим ногами, скамья Скотта, жим стоя, тяга в наклоне, подъём на бицепс, разгибание ног, сгибание ног, тяга нижнего блока, сведение рук, разгибание на трицепс, румынская тяга, ягодичный мост, махи гантелями, шраги

**Кардио:** бег, ходьба

**На время:** планка, стульчик, вис, лодочка, супермен, боковая планка

**Время + вес:** удержание веса
